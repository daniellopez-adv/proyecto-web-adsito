## El cliente
Seleny García se dedica a la comercialización de licores nacionales e importados. Actualmente, busca desarrollar una página web con el objetivo de ampliar el alcance de su emprendimiento y posicionar su licorera a nivel nacional.

## El público
Usuarios y clientes nuevos y antiguos en la tienda.
